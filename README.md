# Chat App - Frontend

This is the frontend of a real-time chat application, built with Next.js and Tailwind CSS for a modern and responsive user interface. It communicates with the backend via REST APIs and WebSockets.

## Features

- Real-time chat functionality using Socket.io
- Secure authentication with JWT
- Responsive UI built with Tailwind CSS and DaisyUI
- Chat history persistence using backend API
- Toast notifications for real-time updates

## Tech Stack

- **Next.js** - React framework for SSR and routing
- **Tailwind CSS** - Styling framework
- **DaisyUI** - UI components for Tailwind
- **Axios** - HTTP client for API requests
- **Socket.io-client** - WebSocket communication
- **Lucide React** - Icon library
- **React Hot Toast** - Notifications
